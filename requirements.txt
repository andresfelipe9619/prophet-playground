# TimesFM, the foundation model. It is by far the heaviest thing here — torch is
# ~1.2 GB on its own, and `pip install timesfm[torch]` resolves to the CUDA build
# and pulls ~3.2 GB of NVIDIA libraries on top (measured). That is the right
# install on a machine with an NVIDIA GPU, and the model will use it: see
# `timesfm_model.best_device`.
#
# **No GPU? Install the CPU wheel instead** and save those 3.2 GB:
#
#     pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
#
# The weights are downloaded separately from HuggingFace on first use and cached
# under ~/.cache/huggingface. Licence note, because it differs from everything
# else here: TimesFM weights up to 2.5 are Apache-2.0, and 3.0's — the default,
# since this runs locally — are non-commercial and non-production. See
# `lottery/models/timesfm_model.py:CHECKPOINT`.
timesfm>=2.0
torch>=2.0
