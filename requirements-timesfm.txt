# TimesFM, the one genuinely optional dependency. See docs/models.md.
#
# This is a **third** requirements file, and the reason it is allowed to exist
# when the deploy-only one was deleted is the opposite of that one's: this list
# does not duplicate what the app needs, it adds something the app runs fine
# without. `lottery/models/timesfm_model.py:is_available()` is the switch, the
# dashboard hides the model when it is off, and the backtest flag is opt-in. No
# surface silently drops a model because this file was not installed.
#
# **Install the CPU wheel of torch unless you actually have a GPU.** Plain
# `pip install timesfm[torch]` resolves to the CUDA build and pulls ~3.2 GB of
# NVIDIA libraries on top of torch's own 1.2 GB — measured in this repo's
# sandbox, on a machine with no GPU at all. The CPU wheel is a fraction of that
# and forecasts six ball positions in one pass either way:
#
#     pip install -r requirements-timesfm.txt \
#         --extra-index-url https://download.pytorch.org/whl/cpu
#
# The model weights are downloaded separately from HuggingFace on first use and
# cached under ~/.cache/huggingface.
#
# Licence note, because it is not the same answer as everything else here:
# upstream distributes TimesFM weights **up to 2.5 under Apache-2.0**, and 3.0's
# weights under a separate `timesfm-non-commercial-license-v1.0` restricted to
# non-commercial, non-production use. This project defaults to the 2.5
# checkpoint (`timesfm_model.CHECKPOINT`) for that reason — a dashboard on a
# public URL is production. The `timesfm` package itself is Apache-2.0; it is
# the weights that differ.
timesfm>=2.0
torch>=2.0
