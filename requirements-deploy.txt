# What a hosted dashboard needs, and nothing else. See docs/deployment.md.
#
# This is the third requirements file and the three answer three different
# questions: requirements.txt is "everything, including the scripts and
# Prophet", requirements-test.txt is "what pytest imports", and this one is
# "what dashboard/app.py reaches at runtime".
#
# Two omissions are the whole point:
#
# * prophet + cmdstanpy. They pull a C++ toolchain and compile a Stan model at
#   install time; on a free tier that is most of the build minutes and a good
#   share of the image. The dashboard reaches Prophet only through an option
#   that ships off by default, and `dashboard/baloto_page.py:PROPHET_AVAILABLE`
#   removes that option and explains why when the package is absent — so the
#   app is honest about it rather than raising from inside a spinner.
# * matplotlib + seaborn. Only scripts/summary_charts.py uses them, and the
#   dashboard superseded it for exploratory use. The dashboard's charts are all
#   Plotly.
#
# Add prophet back here if you want the hosted instance to offer it; expect the
# build to take several times longer and the image to roughly double.
